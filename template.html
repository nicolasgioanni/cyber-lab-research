Reproduction method
  1. Create two disposable repositories. Commit an inert marker in one and ordinary text in the other, then replace both files with identical clean text.
  2. Run Gitleaks with the same pinned rule on the current files and on the complete Git history. Redact the matched value in both modes.
  3. Repeat in a fresh worker and compare each count with its expected value. This measures one rule and two scan scopes.
