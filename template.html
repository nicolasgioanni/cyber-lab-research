Planned

Agents

An advisory identifies an affected package. Remediation also requires finding where a project depends on it, changing the right files, and checking the behavior of the result.

Evaluating an agent’s patch

The planned benchmark pairs a synthetic repository with an advisory and a known affected dependency. The agent will be asked to explain the dependency path and submit a patch for review.

Identification
Compare the files, versions, and dependency path cited by the agent with the fixture’s known dependency graph.
Remediation
Inspect the proposed change and rerun the dependency check against the same advisory data.
Regression checks
Run the project’s behavioral tests. Record failed checks and unnecessary changes alongside any successful repair.

Validation

I evaluate defensive tools against fixtures with known outcomes. Each published study identifies the control, records the observations, and explains the limits of the result.

Method

Each of two independent runs created two Git repositories. In one, the first commit introduced an inert marker and the second removed it. The clean control followed the same sequence with ordinary text.

Gitleaks 8.30.1 applied the same lab-authored rule to the current files and the Git history of each repository.

Planned

Retrieval

Retrieval-augmented generation gives a model documents to consult when answering a question. Which documents it receives, and how it uses them, determine what the reader can safely rely on.

Evaluating answers against a controlled corpus

The planned study will use synthetic documents, known permissions, and questions with traceable answers. The retrieval step and the generated answer will be evaluated separately.

Access boundaries
Compare retrieved documents against the test reader’s permissions, including cases where a restricted document would best match the question.
Citation accuracy
Check whether each citation identifies an allowed source and whether the cited passage supports the answer.
Untrusted content
Place irrelevant instructions in a source document and record whether they change the answer. A faithful response should use the passage as evidence and preserve the reader’s original task.
