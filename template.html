Experimental methodPaired controls, redaction, and interpretation

Build a paired control

Create two disposable repositories with the same two commits. Write an inert marker in one and ordinary text in the other. Replace both files with identical clean text.

Change the scan scope

Run the same pinned scanner and custom rule in directory and Git-history modes. Redact the matched values and count only findings in the sample file.

Interpret the result

The experiment measures detection of one known pattern across scan scopes. Production detection rates would require a representative set of real-world cases.
