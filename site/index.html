What stays in
Git history?

A synthetic marker, two commits, and two scan modes. This experiment measures what Gitleaks can still find after a file is cleaned up.

Protocol

How to reproduce it

Read the experiment source ↗

Build a paired control

Create two disposable repositories with the same two-commit structure. Write an inert marker in the first repository and ordinary text in the second. Replace both files with identical clean text.

Change only the scan scope

Run Gitleaks 8.30.1 in directory and Git-history modes. Use the same custom rule in both modes and redact the matched values. Count only findings from the sample file.

Interpret the result

This experiment measures how scan scope affects a known pattern. It does not estimate how many real credentials a scanner would catch in production.
